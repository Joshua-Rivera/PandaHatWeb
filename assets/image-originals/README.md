# Image originals

Keep supplied originals outside `web/public/` so only optimized website assets are deployed. The original poster presentation and Angel Fernández's PNG portrait are retained here.

Most current conference and portrait assets do not have their original uploads in this checkout. The optimizer preserves their existing WebP files and responsive manifest records. It generates only missing outputs by default; `--overwrite` is an explicit regeneration option.

Legacy PNG/JPG originals recovered from the old build and previous design drafts were archived before cleanup. Recovery details are recorded in `web/docs/cleanup-execution.md`. Do not move retired images into active source folders unless intentionally restoring them.
