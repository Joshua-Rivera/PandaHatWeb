# PandaHat design options

These standalone pages share the root data and behavior so they can be compared without duplicating the application logic.

- `editorial.html` is the clean comparison copy of the current Fieldnotes / Signal portfolio.
- `terminal.html` adds a high-contrast instrument-panel direction through `terminal.css`.
- The working baseline remains the root `index.html`.
- `../motion.html` is the animation study gallery for comparing motion directions.

Open from the local server:

- `http://localhost:8080/`
- `http://localhost:8080/versions/editorial.html`
- `http://localhost:8080/versions/terminal.html`
